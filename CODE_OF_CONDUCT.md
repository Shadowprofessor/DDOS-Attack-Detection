# Code of Conduct

This project follows the spirit of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our pledge

We want participation in this project to be harassment-free for everyone, whatever their age, body
size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression,
level of experience, education, socio-economic status, nationality, personal appearance, race,
religion, or sexual identity and orientation.

## Expected behaviour

- Be respectful and assume good intent. Critique code and results, not people.
- Give and accept constructive feedback. Admit mistakes and report results honestly, including misses.
- Keep security discussion responsible: no working exploits against systems you do not own, and no
  attack traffic outside an isolated lab.

## Unacceptable behaviour

- Harassment, insults, personal or political attacks, and sexualised language or imagery.
- Publishing someone's private information without permission.
- Using this project, or its discussions, to plan or support attacks on real systems.
- Any other conduct that would reasonably be considered inappropriate in a professional setting.

## Enforcement

The maintainer may remove, edit or reject comments, commits, issues and PRs that break this code, and may
temporarily or permanently ban a contributor.

To report a problem, open an issue titled **"Conduct report"** with no details, or use the private
channel described in [SECURITY.md](SECURITY.md). The maintainer will follow up privately. Reports are
handled confidentially.

## Scope

This code applies in all project spaces (issues, pull requests, discussions) and when someone
represents the project in public.
